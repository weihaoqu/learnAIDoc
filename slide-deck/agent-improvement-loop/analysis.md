# Analysis

## Topic

Engineering agent improvement loops for students: when iteration helps, how verification changes the loop, and when the system must stop or hand control to a person.

## Audience

Undergraduate or graduate students who already use generative AI but have limited experience designing agent systems.

## Content signals

- technical teaching
- classroom laboratory
- agent systems and feedback
- research-grounded but applied
- process comparison rather than product marketing

## Visual direction

Editorial engineering workbook: warm white paper, dark charcoal text, visible grid, teal for verification, cobalt for attempts, green for passed evidence, amber for budgets, and red for risks. No gradients. Visuals use process diagrams, gates, evidence ladders, and comparison matrices.

## Slide count

13 slides for a 60-minute session.

## Language

English.

## Claim policy

- `REPORTED EVIDENCE`: statement maps to a primary paper.
- `TEACHING SYNTHESIS`: framework or classroom design created for this lesson.
- `BOUNDARY`: limitation, stop condition, or authority constraint.

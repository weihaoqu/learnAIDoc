## Accessibility description

## Speaker notes (2 min)
More iterations can add cost and introduce new defects. Stop when all required checks pass, the attempt budget ends, the latest cycle creates no material improvement, verification signals conflict, or the next action crosses a permission or risk boundary. The loop should hand off before publishing, grading, spending money, contacting people, or changing consequential records unless explicit authority was granted. A numerical self-score is not an adequate terminal state unless the scoring system has been independently calibrated for this task.

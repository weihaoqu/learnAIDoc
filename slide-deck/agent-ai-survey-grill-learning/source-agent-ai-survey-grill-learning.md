# Agent AI Survey: Grill Learning Deck

Source wiki: `_wiki/agent-ai-multimodal-interaction-survey.md`

Paper: Zane Durante et al., "Agent AI: Surveying the Horizons of Multimodal Interaction", arXiv:2401.03568.

Purpose: turn the grill discussion into a fast teaching deck. The deck is not a full paper review. It teaches the conceptual upgrade Q reached through the grill:

```text
Agent AI is not just chatbot + tools.
Agent AI = perception + environment + action + feedback.
```

Key learning path:

1. The survey expands "AI agent" beyond text chatbots and tool calls.
2. Multimodal ability means understanding images, video, audio, text, and environment signals.
3. Agentic ability means using that perception to choose actions, observe feedback, and adjust.
4. A model that only describes classroom video is multimodal, but not yet a classroom agent.
5. In education, multimodal agents raise privacy, fairness, accountability, and wrong-perception-to-wrong-action risks.
6. A useful classroom-agent framework is: perception, environment, action, feedback, evaluation, ethical risk.
7. AI helps learning when students can explain, verify, adapt, and defend the work.
8. AI replaces learning when it generates the main answer and the student cannot defend it.
9. College policy must move beyond "allow" or "ban" toward approved tools, allowed/forbidden uses, consent, disclosure, audit, and human authority.
10. The deepest conceptual upgrade is from "AI tells humans what to do" to "AI participates in the task loop."

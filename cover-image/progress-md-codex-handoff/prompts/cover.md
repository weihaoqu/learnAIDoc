# Cover Prompt — progress.md Handoff

Generate a 16:9 conceptual flat-vector cover image illustrating a **cross-agent handoff workflow** between two AI coding assistants (Codex and Claude Code) that alternate sessions on the same software project, mediated by a shared tracked log file called `progress.md`.

## Core composition

A clean editorial scene with three primary elements arranged left → center → right on the canvas:

- **Left**: A simple flat-vector laptop/terminal silhouette in deep blue, labeled (or marked) with a small **teal/green dot** representing Codex. Inside the terminal, a few abstract code lines.
- **Center (visual anchor, slightly above the horizontal centerline)**: An open notebook or stacked-card stack representing `progress.md`. The top page/card visibly shows a few horizontal text lines (no real legible code), a small markdown-style heading bar (`## ...`), and a tiny down-arrow icon hinting "newest on top." This is the SHARED memory.
- **Right**: A second flat-vector laptop/terminal silhouette in the same deep blue, labeled with a small **soft orange dot** representing Claude Code. Mirror-symmetric to the left terminal.

Connecting the three: two thin **arcing arrows** in a gentle curve — one going from the left terminal up to the notebook, the other from the notebook down to the right terminal. The arrows should suggest a baton-pass / handoff motion, alternating between the two agents. Use a subtle dashed-line style for the arrows.

A faint horizontal **timeline** beneath all three elements with small tick marks, suggesting "across days/sessions." Very low-key, not the focus.

## Palette (cool)

- **Background**: warm off-white or very pale cool gray (#F4F6FA-ish), large breathing room
- **Primary structural color**: deep ink blue (#1E3A5F) for the laptop outlines, notebook outline, primary text
- **Secondary**: muted teal (#3E7B8F) for accents and timeline
- **Two accent dots only**:
  - Codex marker: clean teal-green (#2EB67D)
  - Claude marker: warm soft orange (#E08443)
- Optional pale yellow (#F5E6C8) as a single soft highlight on the notebook's top page (the "active checkpoint")
- Whitespace: 50%+ of the canvas. The scene should feel airy, not crowded.

## Rendering (flat-vector)

- Flat geometric shapes, no gradients except possibly one extremely subtle radial light behind the notebook
- Crisp 1.5–2px outlines, consistent stroke weight
- Schematic, almost diagrammatic — think editorial illustration in The Atlantic / Stripe Press, not a SaaS hero
- NO realistic humans, NO photographic textures, NO 3D, NO heavy shadows
- The two laptop silhouettes should be visually identical except for their accent dot color (symmetry communicates "either side can pick up")

## Text (title-only)

- **Title text on the canvas**: `progress.md Handoff` rendered in a clean modern sans-serif (DM Sans / Inter / Söhne / similar), in the deep ink blue, weight medium-bold
- Title positioned in the upper-left or upper-center, occupying no more than 30% of canvas width
- Title size large enough to be the second strongest visual element after the central notebook
- **No subtitle**. **No body text. No tags. No code lines containing real prose.**

## Mood (balanced)

- Calm, deliberate, technical-but-friendly
- Neither minimalist-cold nor playful-busy
- Reads as: "two systems cooperating around a shared written record"

## Composition rules

- Visual anchor: the notebook in the center is the symbolic core; both terminals point to/from it
- Strict symmetry between the two terminals (size, position, distance from notebook)
- The handoff arcs should be visually equal and opposite — one rising left-to-center, one descending center-to-right
- 40–60% whitespace
- Aspect ratio: 16:9
- No author/site watermark

## What NOT to include

- No keyboard close-ups, no human hands
- No literal "handshake" iconography
- No corporate logos (no real Claude/OpenAI/GitHub logos — just abstract dot markers)
- No filename labels visible on the notebook (`progress.md` only appears in the title, not redundantly on the illustration)
- No relay-race runners, no batons rendered as physical objects (the arcing arrows ARE the baton-pass)
- No clutter — resist filling whitespace

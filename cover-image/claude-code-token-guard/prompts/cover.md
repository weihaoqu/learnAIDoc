A clean, modern flat-vector conceptual cover for an article about auditing unattended Claude Code token burn.

**Core visual metaphor:** A protective shield in front of a terminal window, guarding a stream of small token dots from being silently drained. The shield should feel like a safety audit, not cybersecurity panic.

**Main composition:** Center-left, a simplified terminal window with a few abstract command lines and a small usage meter. Overlapping it, a blue-teal shield with a checkmark. Around the terminal, a subtle circular arrow loop suggests `launchd` respawn/persistence, but keep it abstract and readable.

**Secondary elements:** On the right side, three small labeled icon groups without too much text: a tiny clock/schedule glyph, a cloud glyph, and a process tree glyph. These represent the three audit surfaces: local process, scheduler, and cloud routine. Use icon-like shapes, not detailed UI screenshots.

**Token detail:** Small glowing dots or coins flow toward the shield and stop there, implying the guard detects runaway usage before it drains the meter. Avoid dollar signs; this is about usage and safety, not finance.

**Color palette:** Cool technical palette: off-white or very pale blue background, slate blue terminal, teal and cyan accents, a small amber warning accent. High readability, calm professional mood.

**Rendering style:** Flat vector, crisp geometric shapes, minimal shadows, no photorealism, no realistic humans, no cluttered code. Use generous whitespace, especially on the lower-right for the title.

**Title text:** "Claude Code Token Guard" in clean modern sans-serif, dark slate, placed in the lower-right area. Make the text legible and correctly spelled.

**Mood:** trustworthy, operational, calm, technical. 16:9 aspect ratio.

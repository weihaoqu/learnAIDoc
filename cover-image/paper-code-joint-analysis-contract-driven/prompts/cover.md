# Cover prompt — Paper-Code Joint Analysis & Contract-Driven Skill Design

**Title (display exactly):** Paper · Code · Contract

## Concept
Flat-vector cover for a wiki entry on (1) a Codex skill that maps research-paper content to its open-source implementation, and (2) the contract-driven methodology that governs how such skills produce stable structured output. Visual idea: a paper document on the LEFT and a code file on the RIGHT, with several slim "mapping" arrows running between them — and BELOW, a small "contract" tile (schema/document icon) showing where both sides agree on a stable JSON+Markdown output format.

## Visual elements
- **Left:** a stylized flat-vector document icon — a portrait-orientation rectangle with horizontal lines (suggesting paragraphs of paper text). A small math-equation glyph (∑ or ƒ) appears near the top of the paper.
- **Right:** a stylized code file icon — same portrait rectangle but with code-block lines (a few `<` `/>` chevrons + indented bars). A small bracket glyph `{ }` near the top.
- **Three slim curved arrows** running between the two icons, going from paper-section markers to code-symbol markers — suggesting "this formula maps to that function." Arrows are steel-blue at 60% opacity; one of the three is highlighted in warm terracotta (the "active" mapping).
- **Below center:** a small flat tile labeled "Contract" — slightly elevated with a soft shadow. Above it, a tiny chevron line connects both the paper and the code to it, suggesting "both sides write to this shared contract."
- **Background:** uncluttered cool gradient — pale ice-blue at top, deeper steel/teal at bottom. Very faint dot grid (10% opacity).
- **Mood:** organized, methodical, calm.

## Color palette (cool)
- Paper + code icon fills: pale ice (#E7F0F5) with steel-blue border (#5B89A6)
- Mapping arrows: steel-blue (#5B89A6) at 60%; one in terracotta (#C97B5A) at 100%
- Contract tile: slightly stronger steel-blue border + pale fill
- Background: pale ice top (#F2F7FB) → steel teal bottom (#3F6E8C)
- Text: deep navy (#1F3445)

## Typography
- Title text — render exactly as: `Paper · Code · Contract`
- Clean modern sans-serif (Inter / Söhne), lower-center, balanced weight
- The three middle dots (·) should be elegant separators
- Small "Contract" label allowed on the lower tile

## Composition
- 55% whitespace
- Paper (left third) — Code (right third) — Contract (below center)
- Title bottom band, lower-center
- 16:9

## Avoid
- Realistic photos
- Specific brand logos (arXiv, GitHub Octocat, OpenAI, Codex)
- More than one accent color (one terracotta arrow only)
- Cluttered look — keep it to 2 main icons + 3 arrows + 1 contract tile
- Aggressive imagery

Graph engineering is presented as a teaching label for moving from one AI chat to an auditable workflow: jobs, arrows, shared state, checks, merges, and human approval.

Core visual idea:
- A messy single AI chat box on the left.
- A clean diamond workflow on the right.
- Planner at top.
- Three parallel worker nodes in the middle.
- Skeptic/checker beneath them.
- Merge node.
- Human approval gate.

Tone:
- Practical AI workflow design.
- Educational, structured, not hype.
- Emphasize inspectable process over magical automation.

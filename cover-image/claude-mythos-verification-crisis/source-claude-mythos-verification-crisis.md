Claude Mythos Preview is Anthropic's restricted-access frontier model for AI-assisted cybersecurity. The article explains why the controversy is not simply whether AI can find vulnerabilities, but whether public evidence is strong enough to justify governance, funding, and access-control decisions around a model framed as risky enough to restrict.

The entry uses the FlyingPenguin critique as an anchor, then compares it with Anthropic's Project Glasswing launch, the Claude Mythos system card, AISI's evaluation, AISLE's open-weight reproduction, Anthropic's May 22 update, and Cisco's model-agnostic Foundry Security Spec framing.

Core message: AI security claims should be read as evidence chains. A claim like "thousands of high-severity vulnerabilities" needs CVE/advisory mapping, reproduction steps, severity distribution, false-positive and duplicate rates, baselines against fuzzers and static analyzers, patch velocity, maintainer confirmation, and cost per validated finding.

The visual should teach evidence before urgency: vendor headline -> technical report -> reproducible artifacts -> independent validation -> procurement / policy / governance decision.

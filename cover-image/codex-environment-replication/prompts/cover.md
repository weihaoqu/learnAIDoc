# Cover Image Prompt — Codex Environment Replication

A clean, conceptual flat-vector illustration depicting the careful, selective migration of a software developer's configuration between two macOS machines. Cool color palette dominated by deep navy blue, slate gray, teal, and soft sky blue, with thin white/cream accent lines. Calm, technical, slightly serious atmosphere — this is not a marketing illustration, it conveys engineering precision.

## Composition

**Left third**: A simplified, flat-vector laptop silhouette in slate gray, slightly tilted in three-quarter perspective. Above it, a soft glowing label reads "`~/.codex/`" in a clean monospace font. Around the laptop, small abstract file icons hover — some are colored deep navy (representing portable config files like AGENTS.md, config.toml), some are colored muted red/orange (representing dangerous files like auth.json, *.sqlite).

**Center**: A horizontal flow of file icons moves from left to right across the canvas. Between the two laptops, a stylized **funnel/sieve** in teal blocks the path. The sieve catches and discards the red/orange files (which fall away into a small "skip" trash icon below). Only the navy/blue files pass through cleanly to the right. Above the sieve, in small clean text, a label: "secret-hygiene filter".

**Right third**: A second simplified flat-vector laptop, also slate gray and three-quarter tilted, slightly larger or brighter to suggest "destination / new machine". Above it, label "`~/.codex/` (new Mac)". The clean blue files arrive and arrange themselves above the laptop, with one small key icon glowing teal labeled "codex login" — emphasizing that authentication is re-issued, not transferred.

## Title placement

Top center, in a clean sans-serif font (clean style), white or very light slate against a soft dark navy band:

## Style guardrails

- **Flat vector only**: no gradients beyond subtle background atmosphere, no painterly textures, no 3D rendering
- **No realistic humans or hands**: file flow happens autonomously
- **40-60% whitespace**: composition breathes, not crowded
- **Cool palette discipline**: navy, slate, teal, sky blue, with muted red/orange used sparingly only for the "rejected files" detail
- **Iconography**: simple geometric file/folder/key/sieve glyphs in the same flat style — think Apple SF Symbols or Linear's icon set
- **Background**: very subtle radial gradient from dark slate (corners) to slightly lighter navy (center), keeping the focus on the central flow
- **No code text inside the file icons** — keep them abstract

## What this image is communicating

The entry is about a script pair that selectively copies a developer's Codex CLI configuration to a new machine, deliberately filtering out credentials, live database files, and machine-specific state. The visual metaphor is: a clean pipeline with a filter in the middle, where one side is the source machine and the other is the destination, and the filter ensures only safe-to-share state crosses over.

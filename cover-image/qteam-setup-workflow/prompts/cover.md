# Cover design
Article title: QTeam — Set Up and Run a Codex–Claude Team
Create a polished 16:9 editorial cover for a practical technical wiki. Use a cool cream background, dark navy typography, teal and muted blue geometric shapes, small warm amber accent. Clean flat-vector illustration, balanced contrast, generous whitespace (about half of the image).
Left: exact article title, professionally typeset in clean modern sans-serif across a few lines: “QTeam — Set Up and Run a Codex–Claude Team”. Make QTeam dominant, the remainder smaller but legible.
Right: an abstract team coordination diagram. One central coordinator node connects to two separate terminal-window cards with small code brackets and a distinct audit card containing a magnifying-glass/checklist symbol. A small human decision bubble sits above the coordinator. Clear orderly connections, separate workspaces. This is conceptual cover art, not a formal protocol diagram. No extra text, logos, watermarks, or realistic humans. Crisp, restrained, contemporary technical publishing aesthetic.

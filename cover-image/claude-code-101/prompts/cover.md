# Cover prompt — Claude Code 101

**Title (display exactly):** Claude Code 101

## Concept

A clean, flat-vector conceptual cover for a wiki entry introducing **Anthropic's Claude Code 101** — the beginner course teaching new users how to work with an AI coding agent through the Explore → Plan → Code → Commit workflow.

The cover should evoke **onboarding / first step into a coding workflow** — not a code-screen photo, not a tutorial mockup. Aim for a conceptual scene: a confident, calm starting point.

## Visual elements

- **Central anchor:** a stylized terminal window or open laptop silhouette, geometric and flat — interior shows three or four soft horizontal "thinking" bars (suggest streaming text, not literal code) accented with a single subtle cursor or chevron prompt mark.
- **Secondary motif:** four small, evenly-spaced flat icons running below the terminal in a row, representing the four phases of the workflow — a magnifying-glass disc (Explore), a list/checkbox card (Plan), an angle-bracket bracket (Code), a check-circle (Commit). Connect them with a slim horizontal line ending in a soft arrow on the right. These should feel like step-markers, not a busy infographic.
- **Background:** uncluttered cool gradient — pale ice-blue at top fading to a deeper steel/teal at bottom. Optional thin diagonal stripe of soft cyan to add depth. Generous whitespace (50%+ breathing room).
- **Mood:** approachable, modern, calm. NOT corporate, NOT dramatic. Conveys "you can start here."

## Color palette (cool)

- Primary: muted steel blue (#3F6E8C / #5B89A6)
- Secondary: pale ice (#E7F0F5 / #CFE0EA)
- Accent: warm sand or terracotta dot (#C97B5A) for the single highlight — used sparingly on one step marker only, suggesting "where you are."
- Text/lines: deep navy (#1F3445)

## Typography

- **Font family:** clean modern sans-serif (Inter, Söhne, or similar geometric humanist).
- **Title placement:** lower-left or lower-center, large but balanced.
- **Title text — render exactly as:** `Claude Code 101`
- No subtitle, no tagline, no body text.

## Composition rules

- Whitespace: 50–60% of canvas
- Visual anchor: terminal/laptop centered upper third
- Step-marker row: lower middle, narrower than the anchor
- Title: bottom band, left-aligned, clean weight (medium)
- No realistic humans, no decorative clip-art, no emoji
- Aspect: 16:9

## Things to avoid

- Realistic photographs / 3D renders
- Snake / Python / brand logos (Anthropic word-mark, Claude character, etc.)
- Cluttered code text — keep it abstract
- Heavy gradients, neon, retro-futurism
- More than one accent color

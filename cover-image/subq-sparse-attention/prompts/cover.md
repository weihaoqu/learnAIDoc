# Cover Image Prompt

Create a conceptual cover image for a technical article about SubQ, a new AI model architecture that replaces dense attention with sparse, content-based attention.

## Visual Concept

A flat-vector illustration showing the contrast between dense and sparse attention:

**Left side** — A dense grid/matrix of connections between tokens, all lit up uniformly, looking congested and expensive (warm red/orange tint to suggest waste)

**Right side** — The same token grid but with only a few precise connections highlighted in bright blue/cyan, most connections faded to near-invisible. Clean, efficient, purposeful.

A diagonal arrow or transformation sweep moves from left to right, suggesting the shift from O(n²) to O(n).

Above the visualization, the text "12M tokens" with a context length indicator bar stretching far to the right.

## Color Direction

MUST use a **cool palette**: deep navy background (#1a2332), bright cyan/blue (#00d4ff) for active attention paths, faded gray (#3a4555) for inactive connections, white for text. Subtle grid lines.

## Composition

- **Whitespace**: 45% breathing room
- **Title**: "SubQ: Subquadratic Attention" in clean sans-serif at top
- **Visual anchor**: The dense→sparse transformation centered
- **No realistic humans**
- **Style**: Flat vector, technical diagram aesthetic, data visualization feel

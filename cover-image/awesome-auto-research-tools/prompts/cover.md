# Cover prompt — Awesome Auto-Research Tools

**Title (display exactly):** Awesome Auto-Research Tools

## Concept

A clean, flat-vector conceptual cover for a wiki entry on the **handsome-rich/Awesome-Auto-Research-Tools** GitHub catalog — a curated, CC0, bilingual map of open-source projects that automate parts of the research lifecycle (literature search → idea generation → experiment loop → paper writing → peer review).

The cover should evoke a **curated map or atlas of tools** — like a tile layout, periodic-table-of-tools, or research wall. Not a single agent, not a code-screen photo. Aim for an organizational-knowledge feel: many cards, calmly arranged.

## Visual elements

- **Central anchor:** an isometric or top-down view of a **5-cluster grid of tile cards**, arranged like categories on a research wall. Five small clusters of 2–4 stylized cards each, slightly offset, with light shadows. Each cluster represents one category — but the cards remain abstract (no readable text on cards, just an icon glyph).
- **Cluster glyphs** (one per cluster, each rendered as a simple flat icon in the top corner of the lead card):
  1. test tube / flask (End-to-End research)
  2. open book or document stack (Deep Research)
  3. gear / cog (Experiment & Code)
  4. puzzle piece or modular block (Skills / Plugins)
  5. clipboard or list-grid (Awesome Lists)
- **Connecting threads:** thin, faint lines linking the clusters in a loose web — suggesting these are related-but-distinct categories on a shared map.
- **Background:** uncluttered cool gradient — pale ice-blue at top fading to deeper steel/teal at bottom. Optional very faint dot grid (15% opacity) to evoke "research notes / wall pinboard" without becoming literal.
- **Mood:** organized, methodical, expansive. NOT corporate, NOT busy. Conveys "this is the map, not the tools themselves."

## Color palette (cool)

- Primary card stock: pale ice (#E7F0F5 / #CFE0EA) with thin steel-blue outlines (#5B89A6)
- Secondary fills: muted steel blue (#3F6E8C / #6D94B0)
- Background: pale ice top (#F2F7FB) → steel teal bottom (#3F6E8C)
- Accent: a single warm terracotta dot or tag (#C97B5A) on one card — used sparingly to add visual warmth and suggest "you are here" / "featured"
- Text/lines: deep navy (#1F3445)

## Typography

- **Font family:** clean modern sans-serif (Inter, Söhne, or similar geometric humanist).
- **Title placement:** lower-center, large but balanced. Allow generous breathing room above and below.
- **Title text — render exactly as:** `Awesome Auto-Research Tools`
- No subtitle, no tagline, no body text. No text on the individual cards.

## Composition rules

- Whitespace: 50–60% of canvas
- Visual anchor: 5-cluster grid in upper two-thirds
- Title: bottom band, center-aligned, clean medium weight
- No realistic humans, no decorative clip-art, no emoji
- Aspect: 16:9

## Things to avoid

- Realistic photographs / 3D renders
- Specific brand logos (GitHub Octocat, project icons, etc.)
- Readable text on any card / tile
- Cluttered / busy "infographic" look
- Heavy gradients, neon, retro-futurism
- More than one accent color

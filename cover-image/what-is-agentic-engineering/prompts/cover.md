# Cover prompt — What is Agentic Engineering

**Title (display exactly):** Agentic Engineering

## Concept
Flat-vector cover for a teaching primer on agentic engineering — the discipline of building software systems where an LLM is one component in a goal-directed loop. Five interacting layers: Prompt / Agent / LLM / MCP / Tools.

## Visual
- Centered: a clean horizontal row of **5 stylized component tiles** connected by slim flow arrows. Each tile shows a simple icon glyph: speech-bubble (Prompt), small robot/bot (Agent), brain-circuit (LLM), network-node (MCP), wrench (Tools).
- The middle tile (Agent or LLM) is lifted slightly with a soft terracotta highlight — the only warm accent.
- Background: cool ice-blue gradient (top) to steel teal (bottom). Subtle dot-grid texture at 10% opacity.

# Cover Image Prompt

Create a conceptual flat-vector cover image for a technical wiki entry about Graphify-style tool memory: turning mixed project artifacts into a queryable knowledge graph for AI coding agents.

## Visual Concept

Show mixed project artifacts flowing into a central knowledge graph:

- Left side: small icons for code files, docs, PDFs, screenshots/images, diagrams, and video frames.
- Center: a clean graph network with typed nodes and edges. Some edges are solid to suggest extracted relationships; some edges are dashed to suggest inferred relationships.
- Right side: an AI coding agent panel asking a targeted question, with a small highlighted path through the graph returning the answer.

The image should communicate "read once, query many times" without using too much text.

## Color Direction

Use technical cool colors: deep navy background, steel blue panels, cyan graph edges, white nodes, and a restrained green accent for the highlighted answer path.

## Composition

- Title text: "Graphify Tool Memory" in clean sans-serif.
- Main visual: artifact icons on left -> graph in center -> agent query panel on right.
- Keep graph organized and readable, not chaotic.
- No realistic humans, no brand logos, no screenshots.
- Flat-vector, crisp 2px line style, technical diagram aesthetic.
- 40-50% whitespace and stable 16:9 layout.

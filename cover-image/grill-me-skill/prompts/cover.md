# Cover prompt — grill-me

**Title (display exactly):** grill-me

## Concept

A clean, flat-vector conceptual cover for a wiki entry on **Matt Pocock's `grill-me` skill** — a tiny Claude Code / Codex skill that flips the agent dynamic: instead of you describing a plan and the agent writing code, the *agent* interviews *you*, one question at a time, walking down each branch of the decision tree until you've thought through every dependency.

The cover should evoke **structured, deliberate questioning** — a decision tree being walked branch by branch, with one node currently in focus. Not literal "interrogation" imagery. The feel is methodical, not aggressive.

## Visual elements

- **Central anchor:** a stylized **decision-tree diagram** rendered as a clean flat-vector graphic. Three or four levels of branching nodes connected by slim lines. Each node is a small flat-circle disc with a single question-mark glyph (`?`) inside, drawn in a clean modern sans-serif weight.
- **One highlighted "current" node** — one disc on the middle level filled with a warm terracotta accent color (the only warm color on the canvas). All other nodes use the cool palette. This represents "the one question being asked right now" — the core mechanic of "ask one at a time."
- **Connecting lines** — branches between nodes are slim, slightly curved (not rigid right-angles), suggesting a thought process. The unhighlighted branches are 60% opacity; the path leading to the highlighted node is 100% opacity.
- **Subtle small dialogue marker** — a small speech-bubble-shaped chevron tail extending from the highlighted node, hinting that the question is being asked *now*. Keep it minimal.
- **Background:** uncluttered cool gradient — pale ice-blue at top fading to deeper steel/teal at bottom. Optional very faint dot grid (10% opacity) for subtle texture.
- **Mood:** structured, deliberate, calm. NOT aggressive, NOT corporate. Conveys "methodical conversation."

## Color palette (cool)

- Nodes & lines: muted steel blue (#3F6E8C / #5B89A6 / pale fills #E7F0F5)
- Background: pale ice top (#F2F7FB) → steel teal bottom (#3F6E8C)
- Accent (the highlighted node only): warm terracotta (#C97B5A)
- Text/lines: deep navy (#1F3445)

## Typography

- **Font family:** clean modern sans-serif (Inter, Söhne, or similar geometric humanist).
- **Title placement:** lower-center, large but balanced. Allow generous breathing room above and below.
- **Title text — render exactly as:** `grill-me`
- The title should be set in lowercase (matches the skill's actual name). No subtitle, no tagline, no body text.

## Composition rules

- Whitespace: 50–60% of canvas
- Visual anchor: decision tree centered in upper two-thirds
- Title: bottom band, center-aligned, clean medium weight, lowercase
- No realistic humans, no decorative clip-art, no emoji
- No literal "interrogation" or spotlight imagery (avoid harsh / threatening connotations)
- Aspect: 16:9

## Things to avoid

- Realistic photographs / 3D renders
- Specific brand logos (Claude, Codex, GitHub Octocat, Anthropic mark, etc.)
- Aggressive / threatening visual metaphors (interrogation rooms, spotlights, magnifying glass over a person)
- Cluttered / busy "infographic" look — keep the tree to 3-4 levels max
- Heavy gradients, neon, retro-futurism
- More than one accent color (terracotta on one node only)

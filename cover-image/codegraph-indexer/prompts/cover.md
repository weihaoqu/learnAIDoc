# Cover Image Prompt — CodeGraph Token-Cutting Indexer

Flat-vector minimalist illustration, 1920x1080, 16:9 widescreen. Conceptual editorial style with cool palette (deep navy, teal, sky blue, with single warm accent of soft amber).

Center-left: a stylized knowledge graph of code symbols — small geometric nodes representing functions, classes, files, connected by clean curved edges. The graph has 8-12 nodes laid out organically (not grid). Each node should be a simple geometric shape (circle for function, square for class, hexagon for file) in flat shades of teal/navy with subtle 1px highlights.

Center-right: a downward-pointing arrow or funnel from a large cloud of dense token particles (small dots, light navy) at the top into a small focused stream of fewer tokens at the bottom, illustrating dramatic token reduction. The funnel should feel like the graph is filtering/distilling tokens.

Background: very subtle grid or dot-pattern in pale teal at 15% opacity. Generous whitespace (40-60% breathing room). Top-left corner: a tiny abstract sqlite-database hint (3-stacked-disk icon, 40px size, deep navy).

Mood: clean, technical, "infrastructure tool" aesthetic — like a Stripe Atlas or Linear product page illustration. NO text on the image. NO realistic humans. NO 3D shading, only flat vector with optional 1-2px stroke outlines.

Composition: visual anchor center-left (graph), secondary anchor center-right (funnel), supporting element top-left (database icon). Strong negative space on bottom-right.

Colors: primary #0F2A44 (deep navy), #3FA9C9 (teal), #88D4E8 (sky blue), accent #F5C26B (soft amber, used VERY sparingly — only for "after" stream of tokens to suggest "savings").

Avoid: gradients, drop shadows, photorealism, brand logos, AI/ML cliches (no robot heads, no brains, no neural net hairballs).

# Cover prompt — codegraph

**Title (display exactly):** codegraph

## Concept
Flat-vector cover for a wiki entry on the codegraph tool — a pre-indexed code knowledge graph that lets Claude Code agents skip costly grep/glob/Read discovery and query a structural graph instead. Visual idea: a clean node-edge graph on the LEFT representing the indexed codebase, with a single highlighted edge pointing into a small "MCP" gateway box on the RIGHT, suggesting "agent queries the graph through one tool."

## Visual elements
- **Left two-thirds:** a tidy network graph of 8-12 nodes connected by slim curved edges. Nodes are small flat-circle discs in steel-blue; edges are thin lines. The graph should look organized, not random — suggest tree/AST structure with some "branching" feel rather than a chaotic web.
- **One node** (off-center, slightly upper-middle) is highlighted in warm terracotta — the "current query" focus point. From this node, a stronger arrow leads to the right.
- **Right side:** a small, clean rectangle labeled "MCP" (or just a chevron-arrow → glyph) showing where the agent connects. Keep this small and clean.
- **Background:** uncluttered cool gradient — pale ice-blue at top fading to deeper steel/teal at bottom. Optional very faint dot grid (10% opacity) for "indexed structure" texture.
- **Mood:** organized, methodical, efficient. NOT busy, NOT chaotic. Conveys "pre-indexed and ready."

## Color palette (cool)
- Nodes: pale ice (#E7F0F5) with steel-blue border (#5B89A6)
- Lines / edges: muted steel blue (#5B89A6) at 60% opacity
- Highlighted node + active edge: warm terracotta (#C97B5A)
- MCP gateway box: pale ice with steel-deep border
- Background: pale ice top (#F2F7FB) → steel teal bottom (#3F6E8C)
- Text: deep navy (#1F3445)

## Typography
- Title text — render exactly as: `codegraph`
- Clean modern sans-serif (Inter / Söhne), lowercase, lower-center, balanced weight
- No subtitle, no tagline
- Tiny "MCP" label is OK (only label allowed besides title)

## Composition
- 50-60% whitespace
- Graph network upper-left/center
- MCP gateway upper-right
- Title bottom band, lower-center
- 16:9

## Avoid
- Realistic photos
- Specific brand logos (Claude, Anthropic, GitHub Octocat)
- More than one accent color (terracotta on one node + one edge only)
- Cluttered "infographic" feel — keep node count under 12
- Aggressive imagery
- Trees, leaves, organic shapes — keep geometric

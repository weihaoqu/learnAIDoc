# Cover Image Prompt

Create a conceptual flat-vector cover image for a wiki entry about SkillsMP as a map of the public agent-skills ecosystem.

## Visual Concept

Show a searchable skills map rather than a shopping marketplace:

- Center: a large clean search/map interface with a search bar and three tabs: occupations, creators, repositories.
- Around it: many small `SKILL.md` cards arranged like nodes on a map, grouped into clusters.
- A magnifying glass highlights one card, and a shield/checklist icon sits nearby to suggest "inspect before installing."
- Subtle arrows point from discovery to source review, not directly to install.

The image should communicate "find, inspect, then decide" rather than hype.

## Color Direction

Use an elegant professional palette: off-white or light gray background, dark graphite text/panels, restrained blue accents, and small amber highlights for selected skill cards.

## Composition

- Title text: "SkillsMP" in clean sans-serif, large and readable.
- Main visual: searchable map interface centered with card clusters around it.
- 45-55% whitespace; calm, organized, trustworthy.
- No realistic humans, no brand logos, no decorative blobs.
- Flat-vector style with crisp lines and small icons.

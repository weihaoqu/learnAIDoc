# Mood Application

Use medium contrast, normal saturation, balanced visual weight. The cover should feel practical, calm, technical, and easy to scan.

# Font Application

Use clean geometric sans-serif typography. Modern, minimal letterforms. Keep all text crisp and readable.

# Composition

Type composition:
- Conceptual layout with a central command palette or terminal window as the anchor.
- Surround the center with connected skill cards or nodes, each represented by simple icons: bug, compass, shield, browser window, Python mark, document, research flask.
- Use thin connector lines to suggest an operating workflow rather than a chaotic network.

Visual composition:
- Main visual: a Codex command palette choosing from reusable skill playbooks.
- Layout: centered command palette on the left-middle, skill nodes arranged in a clean arc to the right and bottom.
- Decorative: subtle code brackets, checkmarks, flow arrows, and small terminal glyphs.

Color scheme:
- Background: deep desaturated navy or blue-gray.
- Primary: cool cyan and soft blue.
- Accent: small touches of green for verified workflows and amber for decision points.
- Keep the palette varied enough to avoid a single flat blue theme.

Rendering notes:
- Flat-vector style, crisp shapes, no photorealism, no people, no 3D.
- Light texture is acceptable, but the design should remain clean and professional.
- Do not create a busy dashboard; preserve whitespace and hierarchy.

Type notes:
- The title should be the only visible text.
- Avoid tiny labels inside nodes; use icons instead of words.
- The title must not overlap the command palette or skill nodes.
- Do not write "select skill", "run workflow", "terminal", "prompt", or any other interface label.

Palette notes:
- Cool technical base with restrained accent colors.
- Use contrast to separate the command palette, connector lines, and skill nodes.

This wiki entry is Q's operating manual for the installed Codex and Claude Code skill stack. It explains when to use each skill, how invocation differs across runtimes, and how skills combine into practical workflows for understanding code, planning work, debugging, testing, security review, financial modeling, hardware work, writing, and academic research.

Core themes:
- Skills as task-specific playbooks
- Quick chooser table for selecting the right workflow
- Explicit invocation with `Use skill-name`, `$skill-name`, or Claude Code slash commands when available
- Sequential workflow: understand, decide, implement, verify, review
- Practical skill groups: everyday coding, testing, security, finance, hardware, writing, research, ops

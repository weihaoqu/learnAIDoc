This wiki entry is an operating manual for Q's installed Codex skill stack. It explains when to use each skill, how to ask Codex for it explicitly, and how skills combine into practical workflows for understanding code, planning work, debugging, testing, security review, Python setup, writing, and academic research.

Core themes:
- Skills as task-specific playbooks
- Quick chooser table for selecting the right workflow
- Explicit invocation with `$skill-name` or `Use skill-name`
- Sequential workflow: understand, decide, implement, verify, review
- Practical skill groups: everyday coding, testing, security, Python, writing, research

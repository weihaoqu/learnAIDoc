# Composition
Visual composition:
- Main visual: A split composition. On the left, a fading/dissolving keyboard and code editor (representing the old era). On the right, a human silhouette standing at a control panel with multiple glowing screens/terminals radiating outward — each screen showing a different agent task (a gear, a flask/beaker for research, a checkmark, a document). Circular loops/arrows connecting the agent screens suggesting the "loopy era" of continuous improvement.
- Layout: The split runs diagonally from upper-left to lower-right. Title "The End of Coding" positioned top-center, large and bold. Subtitle area could show a subtle "skill issue" text element.
- Decorative: Floating loop arrows in the background suggesting recursive cycles. Small token/coin icons flowing from the human to the agents representing token throughput. A subtle "700" number ghosted behind the research flask.

# Claim Pipeline for AI Security Announcements

## Overview

This infographic shows how AI security claims should move from vendor announcement to independently validated evidence before they drive policy, procurement, or governance decisions.

## Learning Objectives

The viewer will understand:
1. The five-step evidence chain for AI security announcements.
2. Why independent validation is the key checkpoint before decisions.
3. The failure mode called a verification crisis.

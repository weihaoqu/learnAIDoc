## Main Topic

This infographic visualizes the evidence chain that should connect AI security announcements to policy, procurement, or governance decisions.

## Learning Objectives

After viewing this infographic, the viewer should understand:
1. AI security announcements should be evaluated as a multi-step evidence chain.
2. Independent validation should come before high-stakes governance or procurement decisions.
3. A verification crisis happens when decisions outrun the evidence that survived earlier checks.

## Target Audience

- **Knowledge Level**: Beginner to intermediate
- **Context**: LearnAI wiki readers learning how to evaluate claims about frontier AI cybersecurity capability
- **Expectations**: A clear, memorable visual summary of the claim-verification sequence

## Content Type Analysis

- **Data Structure**: Linear process
- **Key Relationships**: Each step should feed into the next; the final decision depends on earlier evidence quality
- **Visual Opportunities**: Use a left-to-right flow with icons, arrows, and a warning callout for the failure mode

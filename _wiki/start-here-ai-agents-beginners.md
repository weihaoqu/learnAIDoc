**New to AI agents and Claude Code? This hub gives you a recommended reading order across five entries — from conceptual orientation to hands-on use to a full learning roadmap.**

## Recommended Reading Order

### Step 1 — Understand what this is (15 min)
**→ [What is Agentic Engineering?](/learnAIDoc/wiki/what-is-agentic-engineering/)**

Defines the field: what makes a system "agentic," how LLM-mediated software differs from traditional software, and why new engineering skills are needed. Start here if you're coming from a software background or need to explain this to others. Covers the distinction between prompting, tool use, and full agentic orchestration.

### Step 2 — See it through a non-technical lens (10 min)
**→ [Vibe Coding 新手指南](/learnAIDoc/wiki/vibe-coding-beginners-guide/)**

If you or your students have no coding background, this primer explains vibe coding — AI-assisted development where you describe intent in natural language — without assuming programming knowledge. Good for understanding the user side of what Claude Code enables, and for onboarding non-CS students or colleagues.

*(Skip if you're a developer — go straight to Step 3.)*

### Step 3 — Get hands-on with Claude Code (30 min)
**→ [Claude Code 101](/learnAIDoc/wiki/claude-code-101/)**

Anthropic's official free course. Covers installation, first session, how to think about context, and the core mental model. The right starting point if you want to actually use Claude Code, not just understand what it is. Includes interactive exercises.

### Step 4 — Build the vocabulary and workflow model (20 min)
**→ [AI Agent Primer — The Vocabulary Ladder and 18-Step Workflow](/learnAIDoc/wiki/ai-agent-primer-ladder-workflow/)**

Gives you the vocabulary to discuss agents precisely: the difference between an LLM call, a tool, an agent, and an orchestrator. Includes an 18-step ladder from simple prompting to multi-agent systems. Use this as a reference after you've done Step 3 — it will help you understand what you're building toward.

### Step 5 — Map the full learning journey (30 min)
**→ [Agentic AI Engineer Roadmap 2026](/learnAIDoc/wiki/agentic-ai-engineer-roadmap-2026/)**

Eight pillars from prompt engineering to production deployment. The most comprehensive orientation to where this field is going and what skills matter. Read this last so you can place what you've learned in a larger structure.
